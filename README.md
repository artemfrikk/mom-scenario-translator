# Переводчик сценариев «Особняков безумия»

Браузерный переводчик пользовательских сценариев для «Особняков безумия» (Mansions of Madness, 2-я редакция), сделанных в [Valkyrie](https://github.com/NPBruce/valkyrie).

**Открыть переводчик:** https://artemfrikk.github.io/mom-scenario-translator/

Ничего устанавливать не нужно: всё работает прямо в браузере, сценарии никуда не загружаются.

## Что умеет

- **Открывает любой сценарий.** Перетащите файл `.valkyrie` на страницу или подключите папку `Download` Valkyrie, и переводчик покажет все скачанные сценарии и сколько в каждом уже переведено.
- **Переводит автоматически.** Через Google Переводчик или встроенный переводчик Chrome (без ограничений по объёму, работает прямо на компьютере).
- **Переводит через ChatGPT или Claude.** Для длинных историй: переводчик готовит запрос порциями, вы вставляете его в чат, а ответ обратно. Получается живее, чем у Google.
- **Не ломает игру.** Значки `{will}`, `{c:…}`, теги `<b>` и прочие команды Valkyrie защищены от перевода и проверяются после него.
- **Помогает вычитать.** Все тексты рядом с оригиналом, фильтр «только без перевода», поиск и замена, словарь игровых терминов.
- **Сохраняет аккуратно.** В сценарий добавляется `Localization.Russian.txt`, остальные файлы не меняются. В Chrome, Edge и Яндекс Браузере перевод сразу записывается в папку Valkyrie.
- **Помнит работу.** Незаконченный перевод хранится в браузере, можно закрыть вкладку и продолжить позже.

## Как сыграть в переведённый сценарий

1. Откройте сценарий в переводчике и нажмите «Перевести».
2. Сохраните результат. Если папка Valkyrie не подключена, положите скачанный файл в папку `Download` внутри папки данных Valkyrie (обычно `C:\Users\<ваше имя>\AppData\Roaming\Valkyrie\Download`).
3. В настройках Valkyrie выберите русский язык.
4. В списке сценариев переключитесь в режим **офлайн**: иначе при обновлении Valkyrie может скачать оригинал поверх перевода.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты
npm run build    # сборка в dist/
```

- `src/translate/` пакет сценария, защита значков, машинный перевод, запросы для чат-ассистента, термины, библиотека сценариев.
- `src/format/` чтение и запись файлов Valkyrie (INI и локализация).
- `src/ui/` интерфейс переводчика.

Публикация: при каждом пуше в `main` GitHub Actions собирает сайт и выкладывает его на GitHub Pages (Settings → Pages → Source: GitHub Actions).

Переводчик вынесен из [редактора сценариев](https://github.com/artemfrikk/mom-scenario-editor), который пока в разработке.
